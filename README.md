# Ludo Web

Simple local hotseat Ludo-like game built with React + TypeScript (MVP).

Features in this initial scaffold:
- React + Vite + TypeScript project
- Local hotseat multiplayer (2–4 players)
- Dice roll, move tokens onto board by rolling 6
- Basic movement around a 52-cell track and simple captures
- Safe spots where tokens cannot be captured

What's next (to be added):
- Proper home/finish stretch rules and win detection
- Improved graphics and animations
- Optional single-player AI and online multiplayer

Run locally:

1. Install dependencies

   npm install

2. Start dev server

   npm run dev
